העלאה ל-GitHub Pages: צור מאגר ציבורי, העלה את כל תוכן התיקייה (כולל lib/), Settings → Pages → Deploy from branch → main / root. הכתובת: https://USER.github.io/REPO/
התקנה בטלפון: פתח את הכתובת ב-Chrome → תפריט → "הוסף למסך הבית" (ב-iPhone: Safari → שיתוף → הוסף למסך הבית).
גיבוי: הגדרות → "הורד גיבוי". שחזור: הגדרות → בחר קובץ גיבוי.
לעדכון גרסה: החלף קבצים ושנה את V ב-sw.js (למשל v1.0.1). הנתונים ב-IndexedDB לא נמחקים.
