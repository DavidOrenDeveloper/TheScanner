# כתב כמויות ומפרט – חיפוש חכם (גרסה 2.0.0)

אפליקציית PWA בעברית (RTL) לחיפוש והצלבה של כתב כמויות (Excel) ומפרט טכני (PDF). פועלת כולה בדפדפן, בחינם, והנתונים נשמרים במכשיר.

## מבנה התיקייה

```
index.html            דף הכניסה
manifest.json         הגדרות התקנה כאפליקציה
sw.js                 Service Worker (עבודה בלי אינטרנט + עדכוני גרסה)
reset.html            ניקוי מטמון האפליקציה אם משהו "תקוע" על גרסה ישנה
css/style.css         כל העיצוב
assets/icons/         אייקונים
js/core.js            מנוע החיפוש (עברית, מילון, כתיב דומה, השוואה)
js/embed-worker.js    המודל הסמנטי רץ כאן ברקע, כדי שהמסך לא יתקע
js/app/               קוד האפליקציה, מחולק לפי נושא (נטען לפי סדר המספרים)
js/vendor/            ספריות חיצוניות (SheetJS, PDF.js, ExcelJS, pdf-lib, transformers/onnx)
```

## העלאה ל-GitHub Pages
מוחקים את כל התוכן הישן של התיקייה, מעתיקים פנימה את כל הקבצים והתיקיות האלה, ומעלים דרך GitHub Desktop.
Settings → Pages → Deploy from branch → main / root.

## עדכון גרסה
מחליפים את הקבצים ששונו ומעלים את מספר הגרסה בשני מקומות: `V` ב-`sw.js` ו-`APPV` ב-`js/app/01-state.js`. הנתונים ב-IndexedDB לא נמחקים.
אם קובץ חדש נוסף ל-`js/app/`, מוסיפים אותו גם ל-`index.html`, לרשימה ב-`sw.js` וב-`APPFILES` (ב-`01-state.js`).
